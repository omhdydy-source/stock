쉽게 예를 들어 설명드리면,

​

시작할 때 11000 달러로 해서, 최초 매수 주식 총액이 10000, Pool 현금이 1000 이라면

​

최초 주식 평가액 = 10000 = 앞으로 주가 변동에 따라 계속 바뀌어감..

최초 V = 최초 주식평가액 10000 = 이후 매 2주마다 상승율에 따라 점점 올라가게 됨

​

V min = V의 80% = 10000 * 80% = 10000 * 0.8 = 8000

V max = V의 125% = 10000 * 125% = 10000 * 1.25 = 12500

​

Pool 비중 = Pool / 현재 V = 1000 / 10000 = 0.1 = 10%  입니다

​

기본 상승율 = Pool 비중 / 10 = ( Pool / 현재 V ) / 10 = 1000 / 10000 / 10 = 0.01 = 1%

​

내 주식 평가액이  V 보다 위쪽이면 상승율에 0.005 = 0.5% 추가. 아니면 추가 상승율 없음.

​

매 2주 주기로 다음 V를 계산하는데 

다음 V = 기존 V x ( 1 + 기본 상승율 + (추가 0.5%) ) + 적립금 - 인출금

 = 10000 x (1 + 0.01 + 0.005) + 0 - 0 

 = 10000 x 1.015 + 0 - 0

 = 10150

​

'다음 V' 에 80% 125%로 다음 V min, 다음 V max 는 또 계산되는거고..

​

다음 V min = 다음 V의 80% = 10150 * 80% = 10150 * 0.8 = 8120

다음 V max = 다음 V의 125% = 10150 * 125% = 10150 * 1.25 = 12687.5
